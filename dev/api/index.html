PLNRUV — Module
PLNRUV

Poisson-lognormal differential expression with confounder adjustment, combining CATE of Wang J. et al., Ann. Stat. (2017): https://doi.org/10.1214/16-AOS1511 and the MOUTHWASH generalisation of Gerard D. & Stephens M. The compositional offset of sequencing data is a latent factor with loadings fixed to one.

PLNRUV.thin_2group — Function
thin_2group([rng,] counts; ngenes, nsamp, nctrl = 0, prop_null = 0.9, signal = Normal(0, 0.8), ctrl_signal = Dirac(0), group_prop = 0.5, target_cor = Float64[])

simulate a two-group differential expression data set from real counts (genes in rows, samples in columns) ngenes genes and nsamp samples are drawn at random, nctrl genes are negative controls, a proportion propnull of the other genes are null and the log2 fold changes of the rest are drawn from signal ctrlsignal allows controls that are only approximately null (e.g. Normal(0, 0.1)) target_cor sets the correlation between the group indicator and the first surrogate variables (confounding) return the thinned counts with samples in rows and genes in columns (the orientation used by the models)

PLNRUV.assign_groups — Function
assign_groups(rng, U, target_cor; group_prop = 0.5)

assign samples to two groups so that the group indicator has a target correlation with the columns of U a latent w = U * r + noise is thresholded at its quantile, and for a Gaussian w cor(1{w > t}, U[:, k]) = r[k] * φ(t) / sqrt(p * (1 - p)) with t the (1 - p) quantile

Empirical Bayes

PLNRUV.pln_mouthwash — Function
pln_mouthwash(Y, X, q; controls = Int[], cov_of_interest = size(X, 2), offset_factor = true, nullweight = 10, estimate_λ = true, likelihood = :t, mode = :auto, kwargs...)

empirical Bayes branch: PLN fit (stage 1) followed by MOUTHWASH (stage 2) bⱼ = u'Mⱼ / Rₖₖ with u the column of Q for the covariate of interest; its standard error uses the latent-scale variance of each cell σⱼ² + 1 / ȳᵢⱼ (lognormal variance + Poisson noise, ȳᵢⱼ the expected count), the variances of M itself are too small in the residual rows that are shrunk toward the fitted factors with controls, mode = :auto centres the non-null part of the effect prior at an estimated mode when a shift shared by many genes (a global change of transcription) raises the held-out likelihood (see ash); the null stays at zero

source
PLNRUV.pln — Function
pln(Y, X, q; offsets = log library sizes, offset_factor = true, maxiter = 500, tol = 1e-7, shrink_var = :vash, var_trend = false)

fit the PLN model to counts Y (samples x genes) with design X and q latent factors offsets default to the log library sizes with var_trend = true the overdispersions are shrunk around their trend in the mean log-abundance (the mean–dispersion trend of RNA-seq, as in limma-trend) instead of toward a common scale the fit stops when the relative change of the ELBO is below tol; converged is false if maxiter was reached first

PLNRUV.choose_q — Function
choose_q(Y, X; qs = 0:6, ε = 0.5, nsplit = 2, split = :betabinomial, maxrounds = 5, offset_factor = true, rng, kwargs...)

number of latent factors of the PLN model by count splitting: Y is split in two (beta-binomial thinning with rⱼ = 1 / (exp(σⱼ²) - 1), which splits the latent noise as well as the Poisson noise; split = :binomial for plain binomial thinning), the model is fitted on the first part for each q in qs and scored by the predictive log-likelihood of the second part (averaged over nsplit splits); σⱼ² comes from a fit at the current choice, from q = 0, repeated until the choice is stable (at most maxrounds); kwargs are passed to pln a q whose fit on the first part fails (with one or two residual degrees of freedom a gene that is zero in some samples of that part lets a loading diverge) gets the score -Inf: the data do not support it, and the choice falls back towards q = 0, which has no loadings return the chosen q, the scores of each q (last round) and the choices of the successive rounds

PLNRUV.ash — Function
ash(r, s; nullweight = 10, grid = ash_grid(r, s), df = Inf, mode = :auto, mode_threshold = 0.05)

ash for estimates r with standard errors s, nullweight is the Dirichlet weight of the point mass at zero the non-null part of the prior is unimodal at zero (mode = :zero) or around an estimated mode μ, the null staying at zero (mode = :estimate); mode = :auto estimates μ only when it raises the held-out log-likelihood by more than mode_threshold per estimate (a shift shared by many effects, such as a global change of transcription)

source
PLNRUV.evalues — Function
evalues(r, v, σ, π)

compound e-values of Ramdas A. & Wang R., Hypothesis testing with e-values (2024), Theorem 9.21 / Ignatiadis N., Wang R. & Ramdas A., arXiv:2409.19812 (2024): for rⱼ ~ N(βⱼ, vⱼ) and the prior Σₖ πₖ N(0, σₖ²) (σ₁ = 0 the point mass), the likelihood ratio of the non-null mixture to the null, eⱼ = qⱼ(rⱼ) / N(rⱼ; 0, vⱼ) with qⱼ = Σₖ₌₂ πₖ N(0, vⱼ + σₖ²) / (1 - π₁), equivalently eⱼ = π₁ / (1 - π₁) × (1 - lfdrⱼ) / lfdrⱼ; with an estimated prior they are asymptotically valid compound e-values

source
PLNRUV.ebh — Function
ebh(e; level = 0.05)

e-BH procedure of Wang R. & Ramdas A., J. R. Stat. Soc. B (2022): reject the k* hypotheses with the largest e-values, k* = max{k : k e₍ₖ₎ / K ≥ 1 / level}; controls the FDR under arbitrary dependence for compound e-values. Return a Boolean vector of discoveries

source
PLNRUV.squeeze_var — Function
squeeze_var(s2, d)

limma moderation of Smyth G.K., Stat. Appl. Genet. Mol. Biol. (2004): https://doi.org/10.2202/1544-6115.1027 prior σ²ⱼ ~ scaled inverse χ²(d₀, s₀²) estimated by the method of moments on log s² return the posterior variances (d₀ s₀² + d s²ⱼ) / (d₀ + d) and the prior (d₀, s₀²)

source
PLNRUV.vash — Function
vash(s2, d; shapes = 2.0 .^ (-2:0.5:12), warm = nothing)

vash of Lu M. & Stephens M., Bioinformatics (2016): https://doi.org/10.1093/bioinformatics/btw483 prior on the variances: mixture of inverse gammas σ²ⱼ ~ Σₖ πₖ InvGamma(aₖ, aₖ c) with a common scale c and a grid of shapes aₖ (limma is the one-component case), so that s²ⱼ / c ~ Σₖ πₖ F(d, 2aₖ) π by mix-SQP (as in ash), c by golden-section search; return the posterior 1 / E[1 / σ²ⱼ] and the posterior mixture over the shapes with nonzero weight (mix: weights w, squared scales s2 and degrees of freedom df, genes x components), from which the exact likelihood of a moderated estimate is a mixture of t warm = (c, π) of a previous fit on similar variances (successive EM iterations) starts mix-SQP from π and finds log c by successive parabolic interpolation from the previous log c (the golden-section search on the full bracket when the parabola is not concave or moves too far): the same optimum in a few evaluations instead of about 25
